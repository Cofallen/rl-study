### Python装饰器示例与property用法表 <!-- id:mwgkbi5v0lz03 -->
<sub>2026-11-14 23:30 · 提问</sub>

**问**：帮我总结一下函数py简单装饰器的1例子，加上property等常见装饰器用法表格。

**答**：

装饰器本质是「接收函数、返回新函数」的高阶函数，`@d` 只是 `f = d(f)` 的语法糖。

**最小例子**

```python
import functools

def log_calls(fn):
    @functools.wraps(fn)              # 保留原函数名/docstring
    def wrapper(*args, **kwargs):
        print(f"call {fn.__name__}")
        return fn(*args, **kwargs)
    return wrapper

@log_calls                            # 等价: eps_greedy = log_calls(eps_greedy)
def eps_greedy(q, eps=0.1):
    return q.argmax() if random.random() > eps else random.randrange(len(q))
```

**常见装饰器对照**

| 装饰器 | 作用 | 等价写法 |
|---|---|---|
| `@property` | 方法变只读属性 | `x = property(f)` |
| `@x.setter` | 给 property 配赋值逻辑 | — |
| `@staticmethod` | 不传 `self` | — |
| `@classmethod` | 首参为 `cls`，可做备选构造器 | — |
| `@functools.wraps` | 拷贝 `__name__`/`__doc__` | — |
| `@functools.lru_cache` | 结果缓存、记忆化 | `f = lru_cache(f)` |
| `@dataclass` | 自动 `__init__`/`__repr__` | — |
| `@contextmanager` | 生成器变 `with` 上下文 | — |

小提醒：这题跟页面上的 2.1 探索与利用（$\varepsilon$-greedy 在 exploit 与 explore 间取舍）没关系，属于 Python 基建；若要继续读，重点看 $\varepsilon$ 随步数衰减那一节。

▸ 一句话记住：装饰器 = 把函数包一层再返回，`@d` 只是 `f = d(f)` 的糖。
